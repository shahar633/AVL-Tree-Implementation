# AVL & Binary Search Tree Implementation

## Overview
A functional implementation of a standard Binary Search Tree (BST) and a self-balancing AVL Tree in Python, developed for a university Data Structures course. The project includes the core data structure mechanics alongside an empirical complexity analysis.

## Key Components
* **Data Structure:** Implementation of standard dictionary operations (Search, Insert, Delete) and internal AVL self-balancing mechanics (rotations).
* **Testing:** A custom testing script (`our_tester.py`) for validating basic tree operations.
* **Complexity Analysis:** A comprehensive report (`Complexity_Analysis.pdf`) detailing theoretical complexity (worst-case and amortized) and empirical experiments comparing BST and AVL tree performance under various conditions (e.g., sorted vs. randomized insertion).

## Tech Stack
Python, Data Structures, Complexity Analysis.
